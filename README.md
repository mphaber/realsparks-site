# Real Sparks (root site)

Simple placeholder home page for realsparks.net, served by GitHub Pages.
It links to the games hub at https://games.realsparks.net/ and leaves the
root domain free for future Real Sparks services.

Custom domain: realsparks.net (see CNAME). The www subdomain is pointed at
this site by a CNAME record at GoDaddy. Email records (MX) for
realsparks.net are Google Workspace and are not managed here.
